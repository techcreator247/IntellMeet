# IntellMeet – Smart Video Conferencing Platform

## Project Overview
IntellMeet is a web-based video conferencing application designed to enable users to communicate through online meetings. It provides features such as user authentication, meeting creation, real-time messaging, and audio/video communication.

## Features
- User Registration and Login
- Create and Join Meetings
- Real-Time Audio and Video Communication
- In-Meeting Chat
- Microphone and Camera Controls
- Meeting Participation Management

## Technologies Used

**Frontend:**
- React.js
- Vite
- CSS

**Backend:**
- Node.js
- Express.js
- Socket.IO

**Database:**
- MongoDB Atlas

**Real-Time Communication:**
- WebRTC
- STUN/TURN Servers
- Metered TURN
